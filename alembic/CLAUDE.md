# Alembic Migrations

## Commands
- Generate migration: `uv run alembic revision --autogenerate -m "description"`
- Apply migrations: `uv run alembic upgrade head`
- Rollback one: `uv run alembic downgrade -1`
- Show current: `uv run alembic current`
- Show history: `uv run alembic history`

## Conventions
- Migration messages should be descriptive: "create_users_table", "add_email_to_users"
- Always review autogenerated migrations before applying
- For data migrations (seeding), use `op.bulk_insert()` or raw SQL
- Import models in env.py for autogenerate to detect changes

## Gotchas
- After adding a new model, import it in `app/models/__init__.py`
- JSONB columns need `from sqlalchemy.dialects.postgresql import JSONB`
- Use `server_default=func.now()` for created_at timestamps
